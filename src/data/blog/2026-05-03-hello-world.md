## 시작하며

Swift 코드 블록은 자동으로 syntax highlight됩니다.

```swift
@MainActor
final class ProductFilterStore {
    private(set) var filters: [Filter] = []
    
    func update(_ newFilters: [Filter]) async {
        filters = newFilters
    }
}
```

위와 같이 작성하면 끝입니다.
